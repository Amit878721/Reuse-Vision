# ReUseVision AI — Computer Hardware Detection Using YOLO

ReUseVision AI is a computer vision-based web application that detects internal computer hardware components using YOLO (You Only Look Once).

## Features
- Upload and preview hardware images.
- Detect supported computer hardware using YOLO.
- Display bounding boxes, labels, and confidence scores.
- Show total detected components and class-wise counts.
- Download annotated detection images.

## Technologies Used
- Python
- Flask
- YOLO
- HTML
- CSS
- JavaScript

## Supported Hardware Classes
The application detects only the hardware classes supported by the trained YOLO model.

## Project Purpose
The purpose of this project is to explore AI-based computer hardware detection and support hardware identification through computer vision.
